# Intelligent Resume Screening

## 📌 About the Project

Intelligent Resume Screening is a web-based application that helps recruiters screen and rank multiple resumes against a given job description.

The system extracts text from resumes, identifies relevant skills, compares them with the requirements of the job, and ranks candidates based on their match.

## 🎯 Problem Statement

Recruiters often have to manually review a large number of resumes for a single job opening. This process can be time-consuming and makes it difficult to quickly identify the most suitable candidates.

Our project aims to make the initial screening process faster and more efficient.

## 💡 Solution

Our system allows a recruiter to:

- Enter a Job Description
- Upload multiple resumes
- Extract text from resumes
- Detect relevant skills
- Compare candidate skills with job requirements
- Calculate candidate matching scores
- Rank candidates based on their suitability
